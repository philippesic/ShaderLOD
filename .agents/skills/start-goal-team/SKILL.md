# Start a ShaderLOD goal

Follow applicable [project instructions](../../../AGENTS.md) and consult compact
STATUS with `python3 scripts/project_checkpoint.py show docs/STATUS.md`. Preserve
current authority, allocations and pauses; this skill does not resume execution.

For an explicit new project goal, reconcile objective, acceptance, baseline/best
result, constraints and next decisive step in the existing records. Use
[Operations](../../../docs/AGENT_OPERATIONS.md) for assignments, attempt decisions
and resource procedures. Plan the smallest complete preparation → actual consumer
→ quality/cost → restore slice.

A goal document is not a native runtime Goal. Only an explicit request for that
native facility authorizes its creation, with a token budget only if requested.
Follow the [runtime adapter](../../../docs/T3_AGENT_RUNTIME.md) for existing-Goal
inspection, creation, delegation and continuation. An unavailable facility does
not authorize a substitute schedule or top-level conversation.

Return actual evidence, remaining limits and the next action through the existing
prior-SHA checkpoint workflow. The requested outcome determines completion;
a child handback or failed candidate alone does not finish an unfinished goal.

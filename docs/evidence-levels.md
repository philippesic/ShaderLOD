# Evidence levels

| Level | Meaning |
|---|---|
| source-inspected | Source or historical decision read; no new execution proof |
| cpu-synthetic | Synthetic contract or model run without live inputs |
| cpu-integration | CPU components integrated; no live rendering proof |
| live-functional | Matching runtime receipts prove the stated function only |
| live-performance-qualified | Matching correctness, coverage, health and calibrated comparison evidence |

Compilation is separate. A live label needs a runtime receipt. Foundation cannot produce one. Missing stays missing with a reason. Health has only PASS and FAIL. No level admits an optimization automatically. Philip's words remain "proven generally positive"; the benchmark stage settles the definition.

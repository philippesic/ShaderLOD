## Complementary Unbound r5.9.3: primary-cloud density

BSL's native-zero detail-rejection principle now reaches Unbound's default
Overworld `deferred1` cloud density. Its four positive noise octaves use weights
1, .5, .25, .125 and exact normalization 1.875. Each octave makes two existing
explicit-LOD0 noise reads. After the first octave, the remaining weighted sum is
bounded by .875. A conservative .87501 remainder and negative .001 margin permit
returning zero only when the full native density cannot reach its positive-use
branch. Native sampling positions, march count, TAA, lighting, first-hit, opacity
and depth updates remain byte-identical.

For K reached eligible density calls and R certificates, nominal reads change
from 8K to 8K−6R; no prefix read is replayed. This can avoid six of eight density
reads on an empty sample. Reached R/K, compiler behavior, branch overhead and
whole-frame benefit are unmeasured. The certificate is a family-specific bound,
not a small-contribution threshold or a copied BSL equation.

Eligibility requires Balanced bridge2/enabled1, clear weather, primary Overworld
fragment deferred1, quality2/3 and native materials; DH/Voxy, generated normals,
coating, other passes, absent preset and invalid finite domains retain native
work. Existing noise sampling is unchanged. The pinned PNG noise path is
normalized; effective driver binding remains a runtime observation.

# Current optimization union

Working source inventory for the user-authorized
[union goal](goals/optimization-union-and-measurement.md). This is an implementation
artifact, not a competing task ledger. Parent finalizes IDs as owners inspect
actual source. Each meaningful independently controllable change gets its own
ID; primary and secondary consumers may require separate switches.

This list is provisional and must be exhaustive against executable current
source, optional routes and selectors. A diagnostic ablation is not automatically
an optimization. Closed experiment results remain preserved; they do not
substitute for current code inventory or prove a new port profitable.

Per-feature shader switches will use individual integer uniforms under existing
bridge/global-enable/native-quality guards, avoiding unsupported GLSL bitmask
assumptions. Exact names/IDs are owned by the shared infrastructure owner and
will be frozen before final per-family integration. Owners may propose finer
components and identify previously missed optimizations with source evidence.

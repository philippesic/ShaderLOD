The [structured catalog](../sources/history/catalog.json) maps each original path and input digest to its retained record and file. The original digest identifies the input; transformed structured data has its own integrity digest. Exact text reports retain their original bytes. Large native option maps are stored once as `tested-options` records and referenced by `retained_options_id`.

The [authored-source map](source-recovery.json) identifies recoverable Git blobs and additional source records. Use `git cat-file blob <blob>` from a full clone for Git-backed entries; compare the recovered bytes with the recorded SHA-256. Compiled binaries and exact old worlds were intentionally not retained.

Run `python3 results/historical-evidence-extraction/verify.py` from a full source checkout to validate retained evidence and key reductions without the old checkout or archive. [Extraction scope and deletion decision](result.md).

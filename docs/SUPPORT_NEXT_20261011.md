## Existing product chain

Pinned original archive/member identity and selected effective options enter
[PackSelectionService](../src/main/java/com/pp/shaderlod/packs/PackSelectionService.java),
then loader settings/public Apply and
[PackSelectionTransaction](../src/main/java/com/pp/shaderlod/integration/PackSelectionTransaction.java).
The service validates recipe/state before writes, preserves original ancestry and
owned option backups, selects either native or private generated graph, and
restores the original graph while retaining non-owned edits. Unknown executable
identity, changed state/recipe/archive and conflicting edits must still refuse.
Real Iris consumption, option readback, images and recovery receipts complete the
chain; names in `RECIPES` do not complete it.

There are two existing consumers, which must remain distinct:

- Shader-work adapters consume core bridge/enabled/preset through pinned GLSL
  sites. Photon uses its explicit live-pixel/TAAU path; six families have SSR
  hit-refinement recipes; Bliss/Sildur have uniform volumetric sample budgets.
  Fixed refinement distance bands do not consume advanced distance controls.
  Bliss/Sildur's sample helper is uniform, so it establishes no distance LOD.
- Renderer routes consume original graphs through named `*QuadEligibility`,
  version-specific `MakeUpQuadRuntime` and existing cached-fill or copied-
  submission consumers. They need actual current terrain program/source joins,
  source/options/API/resource gates and original behavior on refusal. Compiling
  eligibility classes or adding an OR/allowlist is not support or a speed gain.

The current service keeps MakeUp, Sildur, BSL and both Complementary families on
their native renderer graph. Bliss uses that graph only with the research flag;
Photon only with its additional original-graph flag. Thus historical refinement
recipes are not automatically the selected On path for every family. Only Photon
is explicitly in `NATIVE_QUALITY_GRAPH`; GLSL fallback on Quality is a different
claim from native graph/option/sidecar restoration. Preserve this distinction.

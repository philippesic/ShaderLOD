# Authored benchmark inputs

Start with [the workflow guide](../docs/benchmarks.md) and [definition contracts](../docs/benchmark-definitions.md). Use `python3 -m shaderlod_host ... --plan` before a live command. A specification limits a run; it does not allocate a machine or approve an optimization.

| Location | Purpose |
| --- | --- |
| `validation-*.json` | Focused real activation and restoration at an explicit native surface/DH mode |
| `profiles/` | Frame or optional stage diagnostics; the interruption control deliberately outlasts a short session deadline |
| `comparisons/` | Short paired routes, untimed quality, observer, installation and interaction controls |
| `qualification/` | Fixed fresh-JVM controls for sensitivity, pause/resume and sustained capture |
| `worlds/` | Initial world identity and prior exposure; raw originals and one working copy live externally |
| `packs/` | Exact original-pack selection for prepared slots |
| `mappings/` | Source-supported labels for observed boundaries; unknown graphs remain unmapped |
| `windows/` | Bounded manual bridge into the allocated interactive Windows console |

The supplied protocols qualify harness behavior. Identity, companion, delay and visual-defect providers are development controls, not optimizations. The sustained protocol deliberately uses two independent JVMs and five-minute windows for both arms; two sessions cannot support a 95% acceptance interval. The six-session slowdown protocol tests rejection sensitivity on one declared configuration. The six-session no-change protocol (`rtx2080ti-null-sessions.json`) compares the original pack with the identity provider in fresh processes; its spread of session effects is the smallest change the machine can resolve, and its policy verdict is expected to be not-promote.

For a real contribution, author its cases, exact enabled sets, eligibility, exposure, stopping rule, budgets and useful-gain/harm/quality policy. Choose opportunity, ordinary, adverse and mechanism-specific cases inside the actual activation envelope. Add a different active pack and relevant compatibility cells before claiming reuse. Keep quality/diagnostics separate from authoritative timing, and test the shipped combination. Do not turn harness fixtures into unseen release evidence.

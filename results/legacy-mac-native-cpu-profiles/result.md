# Native-shader CPU profiles were the useful positive Mac observations

The October 22 consolidation identified binding-certificate caching, quad-command compaction, index-scalar caching and shadow-admission caching as the useful native-shader CPU work. Five families used four controls; Unbound and Bliss used two. Most recorded scenes improved, Bliss was nearly flat, and Reimagined’s repeat was small. These were combined profiles, not isolated gains for each control. Native drift matters, particularly for MakeUp. AstraLex and Solas retained native Mac failures.

## Conditions and limitations

Evidence level: source-inspected historical import. M3 Max Mac, NeoForge 1.21.1, Iris 1.8.12, Sodium 0.6.13, native settings and AA; current graph screens used 1920×1200 coast views. Earlier scenes and builds remain separate. Native means original shader/core Off with ShaderLOD still loaded, not a mod-absent baseline. No new run was performed.

## Decision

Retain as scoped positive leads. Preserve the actual before/middle/return brackets; do not assign one project-wide percentage or infer PC/current-runtime gains.

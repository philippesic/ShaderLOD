# Photon integration attribution

The pinned base is Photon v1.3b by Benjamin Stott (SixthSurge). The explicit
patch manifest contains modified portions of that shader pack; water kernel
specializations also derive from its Gerstner-wave implementation.

Photon uses its own [license agreement](LICENSE.Photon). The copy here retains
the pinned archive's license text with whitespace-only normalization. The pack builder preserves that original license
in every generated derivative. ShaderLOD's original mod/framework code retains
the repository's MIT license; that does not replace Photon's terms for upstream
or derived shader portions.

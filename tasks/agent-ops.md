# Agent operations

## Goal
Make agents effective at sustained optimization development through clear working preferences, appropriate skills and reliable investigation closeout.

## Authorized
Prepare proposals and perform routine development-direction repairs. Discuss shared skills and project conventions with Philip. Philip approved implementing the evidence system and shared closeout skill, with an example for presentation review.

## Done when
Project working preferences, skill responsibilities, evidence presentation and disk-space/cleanup rules are agreed and usable. The agreed closeout procedure has been exercised end to end.

## State
This is one of three readiness blockers. Local checks and pre-commit are established; remote CI is excluded. Routine fixes and tests do not need repeated approval. Machine allocation remains separate. Backups follow readiness.

Implemented evidence model: FINDINGS is a short question/conclusion/result map. Each meaningful investigation has a compact result page with a finding-led title, useful chart or table, explanation, conditions, limitations, disposition, supporting numerical data and executed-source identity. Failed and unresolved investigations receive the same treatment. Raw execution records stay immutable; summaries permit explicit corrections; materially new investigations get new results.

The shared investigation-closeout skill reads a small tracked project specification for presentation, figures, evidence locations and cleanup. Closeout verifies claims, produces the result, updates FINDINGS, assesses retained code, performs authorized cleanup, validates the remaining project and closes the task. Discarded implementations may leave active code only after source and required inputs are recoverable. Shared procedure must respect project authorization and cannot decide scientific acceptance itself.

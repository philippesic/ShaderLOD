# Retained evidence

The fastpath report and dependency-preparation receipt are Git-visible historical
records. Their statements remain scoped to the original attempts. Some links in
the report refer to local raw evidence that is not bundled here; do not interpret
this directory as a complete replay package or an independently verified result.

Keep new compact summaries in `docs/EXPERIMENTS.md` or an explicitly Git-visible
report. Raw captures, runtime configurations and source snapshots remain local
unless deliberately selected for preservation. See [Git and artifacts](../docs/GIT_AND_ARTIFACTS.md).
